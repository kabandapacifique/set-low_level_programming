# 0x04. C - More functions, more nested loops

## Overview
This project covers more functions and nested loops in C.

## Tasks
0. **isupper**: a function that checks for an uppercase character and
   returns 1 if it is, 0 otherwise.

1. **isdigit**: a function that checks for a digit (0 through 9) and
   returns 1 if it is, 0 otherwise.

2. **Collaboration is multiplication**: a function that multiplies two
   integers.

3. **The numbers speak for themselves**: a function that prints the
   numbers from 0 to 9, followed by a new line.
