# 0x02. C - Functions, nested loops

## Overview
This project covers functions and nested loops in C, using `_putchar`
for all output.

## Tasks
0. **_putchar**: a C program that prints `_putchar`, followed by a new line.

1. **I Sometimes Suffer from Insomnia. And When I Can't Fall Asleep, I Play
   What I Call the Alphabet Game**: a function that prints the lowercase
   alphabet, followed by a new line.

2. **10 x Alphabet**: a function that prints the lowercase alphabet 10 times,
   each followed by a new line.

3. **islower**: a function that checks for a lowercase character and
   returns 1 if it is, 0 otherwise.

4. **isalpha**: a function that checks for an alphabetic character and
   returns 1 if it is a letter, 0 otherwise.

5. **Sign**: a function that prints the sign of a number and returns 1, 0
   or -1.

6. **There is no Such Thing as Absolute Value in This World. You Can Only
   Estimate What a Thing is Worth to You**: a function that computes the
   absolute value of an integer.

7. **There are Only 3 Colors, 10 Digits, and 7 Notes; It's What we do With
   Them That's Important**: a function that prints the last digit of a
   number and returns its value.

8. **I'm Federal Agent Jack Bauer, and Today is the Longest Day of My
   Life**: a function that prints every minute of the day, from 00:00 to
   23:59.

9. **Learn your Times Table**: a function that prints the 9 times table,
   starting with 0.

10. **a + b**: a function that adds two integers and returns the result.

11. **98 Battery Street, the OG**: a function that prints all natural
    numbers from `n` to 98, separated by a comma and a space.
