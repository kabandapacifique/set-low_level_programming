# 0x01. C - Variables, if, else, while

## Overview
This project covers variables, `if`/`else` statements and `while` loops in C.

## Tasks
0. **Positive Anything is Better than Negative Nothing**: a C program that
   prints whether a random number `n` is positive, zero or negative.

1. **The Last Digit**: a C program that prints the last digit of a random
   number `n` and whether it is greater than 5, 0, or less than 6 and not 0.

2. **I Sometimes Suffer from Insomnia. And When I Can't Fall Asleep, I Play
   What I Call the Alphabet Game**: a C program that prints the alphabet in
   lowercase using `putchar`.

3. **alphABET**: a C program that prints the alphabet in lowercase and
   then in uppercase using `putchar`.


4. **When I was Having that Alphabet Soup, I Never Thought That it Would
   Pay Off**: a C program that prints the lowercase alphabet except `q`
   and `e`, using `putchar`.

5. **Numbers**: a C program that prints all single digit numbers of base 10
   starting from 0.

6. **Numberz**: a C program that prints all single digit numbers of base 10
   starting from 0 using `putchar` and no `char` variable.

7. **Smile in the Mirror**: a C program that prints the lowercase alphabet
   in reverse using `putchar`.


8. **Hexadecimal**: a C program that prints all the numbers of base 16 in
   lowercase using `putchar`.
