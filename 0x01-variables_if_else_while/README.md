# 0x01. C - Variables, if, else, while

## Overview
This project covers variables, `if`/`else` statements and `while` loops in C.

## Tasks
0. **Positive Anything is Better than Negative Nothing**: a C program that
   prints whether a random number `n` is positive, zero or negative.

1. **The Last Digit**: a C program that prints the last digit of a random
   number `n` and whether it is greater than 5, 0, or less than 6 and not 0.
