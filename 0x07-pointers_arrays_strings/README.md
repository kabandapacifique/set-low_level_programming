# 0x07. C - Even more pointers, arrays and strings

## Overview
This project covers memory functions, pointers, arrays and strings in C.

## Tasks
0. **memset**: a function that fills memory with a constant byte.

1. **memcpy**: a function that copies a memory area and returns a
   pointer to `dest`.

2. **strchr**: a function that locates a character in a string and
   returns a pointer to its first occurrence, or `NULL`.

3. **strspn**: a function that gets the length of a prefix substring
   made only of accepted bytes.

4. **strpbrk**: a function that searches a string for any of a set of
   bytes and returns a pointer to the first match, or `NULL`.

5. **strstr**: a function that locates a substring and returns a pointer
   to its beginning, or `NULL`.

6. **Chess is mental torture**: a function that prints a chessboard
   from an 8x8 array of characters.

7. **The line of life is a ragged diagonal between duty and desire**: a
   function that prints the sum of the two diagonals of a square matrix.
