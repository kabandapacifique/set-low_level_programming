# 0x00. C - Hello, World

## Overview
This project introduces C programming and the compilation process.

## Tasks
0. **Preprocessor**: a script that runs `gcc -E` on the file named in
   `$CFILE` and saves the result in the file `c`.

1. **Compiler**: a script that compiles the C file named in `$CFILE`
   without linking, producing a `.o` file.

2. **Assembler**: a script that generates the assembly code of the C file
   named in `$CFILE` and saves it in a `.s` file.

3. **Name**: a script that compiles the C file named in `$CFILE` and
   creates an executable named `cisfun`.


4. **Hello, puts**: a C program that prints a sentence using `puts`
   and ends with the value `0`.

## Requirements
- Editors: vi, vim, emacs
- Ubuntu 20.04 LTS, compiled with gcc
- Scripts are two lines long and executable
