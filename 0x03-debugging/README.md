# 0x03. C - Debugging

## Overview
This project covers debugging C programs, including writing test mains.

## Tasks
0. **Multiple Mains**: a `0-main.c` file that tests the function
   `positive_or_negative()` with the value `0`.

1. **Like, Comment, Subscribe**: a `1-main.c` file where the code causing
   an infinite loop is commented out.

2. **0 > 972?**: a fixed `2-largest_number.c` that correctly returns the
   largest of three integers.
